How It Works

  1. The extension scans all images on the page
  2. For each image, it checks:
    • Is it from a known Golden Codex source? (arweave.net, etc.)
    • Does its perceptual hash match the registry?
  3. Verified images get a golden glowing halo
  4. A badge appears showing "Golden Codex"
  5. Click the badge to see full provenance details

Test With Extension

  1. Load the extension in Chrome: chrome://extensions
  2. Enable Developer Mode
  3. Click "Load unpacked" and select the browser-extension folder
  4. Open this demo page
  5. Images with "golden-codex" or "arweave.net" in URLs will glow!
